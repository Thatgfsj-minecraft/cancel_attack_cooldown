# cancel_attack_cooldown

取消 Minecraft 攻击冷却时间（1.9+ 攻击冷却）的模组——让每一次挥击都保持全额伤害与击退。

本仓库是 [Xiaoyu-2009/cancel_attack_cooldown](https://github.com/Xiaoyu-2009/cancel_attack_cooldown) 的 fork，默认分支为 `1.20.1-Forge`。
